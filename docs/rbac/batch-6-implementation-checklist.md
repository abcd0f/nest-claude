## 关键要点

### 设计原则

1. **默认拒绝** - 无范围条件的查询返回空结果
2. **并集策略** - 多角色范围取最大可见范围
3. **独立解耦** - 数据范围与功能权限独立
4. **一致性** - 所有操作类型都应用范围检查

### 实现关键

1. **Where 条件合并** - 范围条件 AND 业务条件
2. **部门树处理** - 基于 ancestors 物化路径
3. **资源政策** - 可扩展的字段映射配置
4. **错误处理** - 一致的错误响应策略

### 测试关键
